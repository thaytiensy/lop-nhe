# Lớp Nhẹ

Ứng dụng web miễn phí giúp giáo viên tiểu học giảm tải sổ sách:

- Điểm danh lớp
- Sổ điểm nhanh
- Khung giáo án
- Tin nhắn phụ huynh mẫu

## Chạy local

Mở `index.html` bằng trình duyệt, hoặc dùng bất kỳ static server nào.

## Stack

HTML + CSS + JavaScript thuần. Dữ liệu lưu trên máy người dùng (localStorage).
